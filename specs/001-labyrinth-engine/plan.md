# Implementation Plan: Labyrinth Lab Engine

## Summary
Implement the CLI application `u-lab` in Python using the Docker SDK to spin up, configure, attach to, verify, and destroy containerized Ubuntu Server learning labs. The system will load metadata, setup scripts, walkthrough guides, and assertion verifiers from local declarative directory definitions.

## Technical Context

**Language/Version**: Python 3.10+  
**Primary Dependencies**: `docker` (Python SDK), `pyyaml` (YAML parser), `rich` (terminal formatting & markdown rendering), `click` (CLI framework)  
**Storage**: Local progress and history stored as JSON at `~/.config/u-lab/progress.json`  
**Testing**: `pytest` for engine unit tests and CLI integration testing  
**Target Platform**: Linux (Ubuntu host)  
**Project Type**: CLI application  
**Performance Goals**: Lab startup < 4s, checking/verification runs < 2s  
**Constraints**: Requires Docker daemon running on the host system  
**Scale/Scope**: 6 default lab configurations, 1 CLI entrypoint

    └── ...

├── test_cli.py          # Integration tests for click CLI commands

**Structure Decision**: Selected a single Python package structure (`u_lab/`) with a `tests/` directory at the root. Lab assets are bundled as part of the package data under `u_lab/labs/`.
